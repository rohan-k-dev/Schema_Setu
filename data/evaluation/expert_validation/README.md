# Expert validation data

`sample_outputs.json` is regenerated by `python scripts/run_evaluation.py` from real (offline) system
outputs, covering the §91 categories. Give it to the domain expert(s).

Record ratings in `ratings.json` (copy `ratings.template.json`):
`sample_id`, `scheme_id`, `query`, `profile_summary`, `system_status`, `expert_status`,
`accuracy_rating` (CORRECT / PARTIALLY_CORRECT / INCORRECT), `xai_rating` (XAI_CORRECT / XAI_INCORRECT),
`source_rating` (SOURCE_CORRECT / SOURCE_INCORRECT), `comments`, and for disagreements
`disagreement_cause` (corpus / rule / source_conflict / model / evaluator).
Store reviewer role only (e.g. "agriculture faculty"), not names.

Expert disagreement never changes system output automatically — investigate and log it in
`docs/phase7-bug-register.md`. Until ratings exist every metric is NOT_MEASURED.
Do not describe the results as "government approved".
