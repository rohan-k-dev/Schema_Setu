# Initial Corpus Scope — Phase 1

## Selected Domains

| Domain | Priority | Reason |
|---|---|---|
| Agriculture | HIGH | Core SchemeSetu use case |
| Farmer Welfare | HIGH | Primary target beneficiary |
| Crop Support & Insurance | HIGH | Crop-specific scheme discovery |
| Income Support | HIGH | Direct financial benefits to farmers |
| Irrigation | MEDIUM | Critical for farming |
| Agricultural Mechanization | MEDIUM | Equipment and technology |
| Rural Employment | MEDIUM | Related to farmer livelihoods |
| Livestock & Dairy | MEDIUM | Allied agriculture |
| Financial Inclusion | MEDIUM | Banking, insurance, pension for farmers |
| Rural Housing | LOW | Related rural welfare |

## Selected States (Initial Focus)

The corpus includes **national (central) schemes** applicable to ALL states, plus state-specific schemes for:

| State | Reason |
|---|---|
| Karnataka | Primary test region per project requirements |
| Andhra Pradesh | Active farmer support programs (Rythu Bharosa) |
| Telangana | Active farmer support programs (Rythu Bandhu) |
| Maharashtra | Large farming population, active programs |
| Tamil Nadu | Active farmer protection programs |
| Uttar Pradesh | Largest farming population |

## Selected Scheme Categories

- Income support (PM-KISAN, state equivalents)
- Crop insurance (PMFBY, state schemes)
- Irrigation (PMKSY)
- Solar/energy (PM-KUSUM)
- Mechanization (SMAM)
- Credit (KCC, AIF)
- Rural employment (MGNREGA)
- Organic farming (PKVY, MOVCDNER)
- Horticulture (MIDH)
- Livestock/dairy (DEDS, NLM)
- Social security (PMJJBY, PMSBY, PM-KMY)
- Rural livelihood (NRLM, MKSP)
- Market access (eNAM, AGMARKNET)

## Excluded Categories

| Category | Reason |
|---|---|
| Urban housing (PMAY-Urban) | Not farmer-focused |
| Industrial subsidies | Not agriculture-related |
| Education scholarships | Not within scope |
| Healthcare (Ayushman Bharat) | Not agriculture-focused (may add later) |
| Defence/military | Not relevant |
| Tourism | Not relevant |
| IT/startup programs | Not relevant |

## Coverage Disclaimer

This initial corpus does **NOT** claim nationwide or comprehensive coverage. It is a curated, high-quality starting point focused on agriculture and farmer welfare. Coverage will expand in subsequent phases.
