# User Study — Limitations

> **Status: PLANNED / NOT CONDUCTED.**

- The study has not been conducted, so no usability, comprehension or trust claim can be made.
- The planned sample is small and convenience-based; results would not generalise to all farmers.
- If it is run in demo mode (no API keys), speech recognition and translation are simulated, so voice and
  language ratings would not reflect real service quality.
- Moderated sessions with printed scenarios differ from real use with a farmer's own details.
