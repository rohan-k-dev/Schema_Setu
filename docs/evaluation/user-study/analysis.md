# User Study — Analysis Plan

> **Status: PLANNED / NOT CONDUCTED.**

Once records exist, `evaluation/runners/user_study_runner.py` computes:
- task completion rate (completed ÷ attempted), overall and per task;
- mean completion time of completed tasks;
- comprehension score (correct answers ÷ 3, averaged);
- mean trust, ease-of-use, voice and language ratings;
- counts of qualitative themes: ease_of_use, trust, language, voice, explanation, missing_information, difficulties.

Only descriptive statistics will be reported. With 8–12 participants, significance testing is not appropriate (§156).
